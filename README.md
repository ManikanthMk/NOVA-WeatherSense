# NOVA WeatherSense

Full starter project: ESP8266 + DHT11 + OLED + Rain Sensor + Node.js backend + public-ready frontend.

## Folders
- `backend/` Node.js/Express API, Render config
- `frontend/` responsive dashboard
- `esp8266/` Arduino sketch

## Next steps
1. Deploy `backend` to Render.
2. Put the Render `/api/sensor` URL into the ESP sketch.
3. Put the Render base URL into `frontend/app.js`.
4. Host `frontend` on Netlify/GitHub Pages/Render static hosting.
5. Add device location + OpenWeather forecast in the backend.
